# v0.3.0 release checklist

Bind every result to the reviewed commit and shipped-payload identity. A planned
`v0.3.0` ref is not an existing release. Do not tick gates from predecessor data.

## Offline candidate gates

- [ ] Release validation passes: version/ref consistency, original attribution,
  relocatable five-hook definitions, source hygiene and distribution metadata.
- [ ] All CI-defined router, AI-classifier, model-policy, adapter, lifecycle,
  catalogue, health, standalone, benchmark and release-contract tests pass.
- [ ] Strict deterministic route audit passes 10/10; fuzz passes 5,000 cases.
- [ ] Security regressions refuse host-Python grading, linked/escaping review
  artifacts, substituted workspaces and unowned/protected cleanup targets.
- [ ] Classifier and fallback selections remain exact-allowlisted; duplicate
  delivery and continuations cannot repeat API calls or child assignments.
- [ ] No automatic retries, paid probes, tool-enabled classification or native
  execution-policy bypass has been introduced.
- [ ] Exact root matches, native rejection, child lifecycle/attestation and final
  verification stay distinct; recommendations are not execution proof.
- [ ] Legacy deterministic and optional custom-agent lifecycle tests pass.
- [ ] Health/status stay non-billable and do not provision credentials.
- [ ] Local secrets, telemetry and `autorouter-acceptance.json` are ignored and
  absent from tracked release inputs; no generated bytecode enters the archive.
- [ ] Hosted Python 3.10–3.14 / macOS / Linux / Windows matrix passes for this
  commit, with unsupported POSIX-only benchmark operations labelled explicitly.

Use the complete command list in [README.md](../README.md). Local success does
not establish hosted CI, live classifier quality or real-host compatibility.

## Runtime scope

| Surface | v0.3.0 evidence | Publication statement |
|---|---|---|
| macOS CLI, earlier accepted payload | One automatic classification and correlated child | Limited trial; final security/docs candidate offline-tested only |
| macOS Desktop | Credential inheritance not established | Unverified; exports cannot retrofit a running app |
| Linux CLI | Offline/CI target, no recorded live acceptance | Runtime unverified |
| Windows Desktop/CLI | Offline/CI target, no recorded live acceptance | Runtime unverified; benchmark workspace/review unavailable |
| IDE/non-hook surfaces | Advisory skill path only | Not full hook-driven acceptance |

Do not create paid tests merely to tick this checklist. Further live acceptance
requires separate approval. Installation/update requires exact-byte comparison,
renewed `/hooks` review where needed, and a fresh host boundary.

## Public distribution gates

- [ ] Private vulnerability reporting is enabled and its destination verified.
- [ ] History review has no confirmed unresolved secret exposure; the publisher
  has reviewed public commit identities. Older vulnerable code is not advertised
  as a corrected release.
- [ ] API billing/credits, environment-variable handling, hook trust,
  disable/uninstall and rollback instructions are clear.
- [ ] No guaranteed savings, universal model entitlement, unsupported platform
  claims or implicit root/service-tier changes are advertised.
- [ ] Separate approval covers push, tag, release and visibility changes.
- [ ] Annotated `v0.3.0` resolves to the reviewed commit; clean-room archive
  validation and SHA256 checks pass before distribution.
- [ ] Marketplace and privacy URLs resolve to the immutable reviewed tag.

No distribution action is performed by this checklist or the validator.
